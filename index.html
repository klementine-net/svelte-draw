An infinite canvas for Svelte.

Draw, write, connect shapes with arrows, add pictures, on as many pages as you like. A plain TypeScript engine with a Svelte layer on top, and every shape and tool is a plugin.

Start

Install it, make an editor and show it on a canvas: that is already a whiteboard, used with the keyboard. The toolbar and the panels are yours to build, or to copy from the example.

npm install @klementine/svelte-draw
Getting started
<script lang="ts">
	import { Canvas, defaultPlugins, Editor } from '@klementine/svelte-draw';
	import '@klementine/svelte-draw/draw.css';

	const editor = new Editor({ plugins: defaultPlugins });
</script>

<Canvas {editor} plugins={defaultPlugins} label="Whiteboard" />

How it is built

Everything on the board is a plain record in one store, and every change is a diff. Undo, saving and sharing are listeners on that stream. A kind of shape is one class, a tool is a small state machine, and both come in as plugins. It is structured like the TanStack libraries: the engine is plain TypeScript and knows no framework, so it runs in a test or on a server just the same, and Svelte is a layer on top.

Where it stands

Early development

Draw works, and it is young. Its API will change between releases without notice, and parts of it are little tested. Pin the version you install, and check what is built before you rely on a part of it.

  • Written with Claude: the code, the tests and these pages. The pages are not finished, and not all of them are reviewed yet.
  • It provides the canvas and the logic. You build the toolbar and the menus in your own design, or adapt the demo's.
  • A board open in two tabs updates in both. Working together over a server is not built yet.
