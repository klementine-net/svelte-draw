API

The editor's methods, the hooks of a kind of shape, and the components.

Read from the library's source when this site was built, so it says what the code says. Every method is called on the editor (editor.select(ids)); a method's arguments that name shapes take their ids.

Editor

new Editor({ plugins, store?, initialTool?, assets? }). The editor owns the document (its store and history), the view (camera, selection) and the tools. Its values are signals: .get() reads and is reactive in Svelte, .peek() reads without tracking, .set() writes.

State

readonly store: Store<DrawRecord>
Every record of the document: pages, shapes, files.
readonly history: History<DrawRecord>
Undo and redo of this user's changes.
readonly root: StateNode
The root of the tools' state machines; the tools are its children.
readonly assets: AssetStore
Where files are kept (see EditorOptions.assets).
readonly readOnly = atom(false)
True while the document may be looked at but not changed (see setReadOnly).
readonly camera = atom<Camera>({ x: 0, y: 0, z: 1 })
The view: a point on the screen is the page point × z + (x, y).
readonly viewport = atom({ w: 0, h: 0 })
The canvas's size on screen.
readonly pageId = atom('')
The id of the page being looked at.
readonly selection = atom<readonly string[]>([])
The ids of the selected shapes.
readonly hovered = atom<string | null>(null)
The id of the shape under the pointer, if one is outlined.
readonly brush = atom<Box | null>(null)
The marquee, in page space, while one is being dragged.
readonly cursor = atom('default')
A CSS cursor name.
readonly style = atom<ShapeStyle>(DEFAULT_STYLE)
The style the next shape gets.
readonly editing = atom<string | null>(null)
The shape whose content is being typed into, if any (see startEditing).
readonly erasing = atom<readonly string[]>([])
The shapes the eraser has touched and will remove on release.
readonly focusedGroup = atom<string | null>(null)
The group that was stepped into: clicks pick what is in it, not the group.
readonly snapLines = atom<readonly SnapLine[]>([])
The guides shown while a move or a resize snaps to other shapes.
readonly lasso = atom<readonly Vec[]>([])
The path of a lasso selection while it is drawn (page space).
readonly grid = atom({ show: true, snap: false })
The dot grid: whether it shows, and whether moved shapes land on it. This screen's own.
readonly laser = atom<readonly Vec[]>([])
The trail of the laser pointer (page space): shown for a moment, never part of the document.
readonly culling = atom(true)
False while every shape must be on screen at once (a picture is being made of the page).
readonly pointerPage = atom<Vec>({ x: 0, y: 0 })
Where this user's pointer is on the page (for the others to see).
readonly peers = atom<readonly Peer[]>([])
The other people looking at this document right now (see persist.ts).
clipboard: ShapeRecord[] = []
What was copied last, for a paste where the system clipboard cannot be read.
readonly toolPath = atom('')
The active path of the tool tree, like select.idle.
readonly inputs = { screen: { x: 0, y: 0 } as Vec, page: { x: 0, y: 0 } as Vec, originScreen: { x: 0, y: 0 } as Vec, originPage: { x: 0, y: 0 } as Vec, shift: false, alt: false, meta: false, isDown: false, isDragging: false, pressure: 0.5, isPen: false }
The pointer and modifier keys as of the last event.

Document and pages

Adds a page after the last one and shows it.

Removes a page and everything on it. The last page stays.

The whole document, to save to a file or hand to another editor.

Replaces the document with records. What is loaded is not an undo step. As remote (what storage held: the other tabs loaded it too) nothing is saved or sent for it; as user (a file this user opened) it is saved and sent like any other change.

Measured sizes

getMeasured(id: string): { w: number; h: number } | undefined
The size the renderer measured for a shape whose size the core cannot know (text). It is not part of the document: every screen measures its own, so nothing is written, undone or sent for it. Undefined where nothing has measured (a test, a server).
setMeasured(id: string, size: { w: number; h: number } | undefined)
Called by a shape's view with what it measured; undefined when the view goes away.

Editing

Whether the shape's content can be typed into (its util says so).

Starts typing into a shape: selects it and sets editing, which the shape's view turns into a text field. Everything typed until stopEditing is one undo step.
stopEditing()
Ends typing and keeps what was typed. The shape stays selected.

The resize handle under screen, if the selection has handles there.
deleteSelection()

The shapes, and all that is in them, as records that stand on their own: placed on the page, tied only to each other. This is what goes on the clipboard.

The asset records the shapes show (an image's file), for a clipboard that leaves the tab.

Adds content (from getContent) to the page as new shapes and selects them. With at its middle lands on that page point; otherwise it lands offset down and right of where it came from. assets are the files the shapes show, added where this document lacks them.

Pastes content (the editor's own clipboard by default), its middle at at if given.

Adds dropped, pasted or picked files as shapes around at: for each file, the first kind that says it is made from it (ShapeUtil.fromFile) makes the shape. Other files are passed over. All of it is one undo step.

Flips a switch (ShapeUtil.toggles) on every selected shape that has it.

Whether the selection can be made a group: two or more shapes with the same parent.

ShapeUtil

The base class of a kind of shape. defaultProps, bounds and resize are required; every other hook has a default.

static kind: string
The kind of the records this util owns.
readonly editor: Editor
readonly styles: readonly StyleKey[] = ['color', 'fill', 'size', 'look', 'opacity']
The styles this kind shows; the style panel offers only these for it.
readonly group: boolean = false
True for a kind that is nothing but what is in it (a group): a click on anything in it picks the whole, and resizing it resizes what is in it.
readonly frame: boolean = false
True for a kind that takes in what is dropped on it and cuts it off at its edge (a frame).
defaultProps(): S['props']
Props of a new shape of this kind.
bounds(shape: S): Box
The shape's bounds in its own space (its x/y is the origin).
hitTest(shape: S, point: Vec, margin: number): boolean
Whether point (in the shape's own space) touches the shape, within margin.
outline(shape: S): string
The outline shown while the shape is hovered or selected: an SVG path in its own space.
canEdit(_shape: S): boolean
Whether the shape holds content to type into (a note's text). A double click or Enter then sets editor.editing to the shape, and its view shows the text field.
fromText(_text: string): S['props'] | undefined
The props of a shape of this kind made from pasted plain text. Undefined for a kind that is not made from text.
async fromFile(_file: Blob): Promise<{ props: S['props']; assets: AssetRecord[] } | undefined>
A shape of this kind made from a dropped, pasted or picked file: its props, and the asset records it needs. Undefined for a file this kind is not made from.
assets(_shape: S): string[]
The ids of the asset records the shape shows (an image's file).
toggles(_shape: S): { id: string; on: boolean }[]
Switches the shape offers in the right-click menu (a line's arrowheads).
toggle(_shape: S, _id: string): ShapePatch | undefined
The change when the switch id is flipped.
onEditEnd(_shape: S): void
Called when typing into the shape ends (a text with no words left removes itself).
canResize(_shape: S): boolean
rotate(_shape: S, _angle: number, _pivot: Vec): ShapePatch | undefined
The change when the shape is turned by angle around pivot (page space), for a kind that does not simply turn around its origin (a line moves its two ends instead). Undefined for the usual turn.
handles(_shape: S): ShapeHandle[]
Handles of the shape's own, like a line's two ends. A shape with any shows these instead of the resize box while it is the only one selected.
dragHandle(_shape: S, _handle: string, _point: Vec): ShapePatch | undefined
The change to the shape when its handle handle is dragged to point (page space).
canBind(_shape: S): boolean
Whether a line's end can attach to this shape.
edgePoint(shape: S, from: Vec, to: Vec): Vec
Where a line coming from from towards to (both in the shape's own space, to inside the shape) meets the shape's edge: where an attached arrow stops.
ties(_shape: S): string[]
The ids of the other shapes this one is tied to (the shapes a line is attached to).
retie(_shape: S, _map: (id: string) => string | null): ShapePatch | undefined
The change that re-ties the shape: map gives, for each shape it is tied to, the id to tie to instead, or null to cut the tie. A cut tie leaves the shape where it shows now. Undefined when nothing changes. The editor calls this when a tied shape is moved alone, copied, or loses the shape it was tied to.
resize(shape: S, target: Box, flip: { x: boolean; y: boolean }): ResizeResult<S>
The shape after its bounds are moved to target (in the parent's space). shape is the shape as it was when the resize began; flip says whether the drag crossed over an axis.

Components

From @klementine/svelte-draw, like the classes above. The classes also come from @klementine/svelte-draw/core, the engine alone; the components do not.

Canvas
the surface an editor is shown and worked on. It draws the editor's shapes through the plugins' views, and turns pointer, wheel and key events into the editor's events; every decision about what an event means is the editor's and its tools'.
children sit above the surface (a toolbar, a panel) and do not send it events. Name the canvas with label. Fills its parent: give the parent a size.
Also the canvas's: copy, cut and paste through the system clipboard, and two-finger pinch and pan on a touch screen. The controls are the app's: the canvas brings none.
around puts something around the surface, a context menu's trigger for one. It gets the surface as a snippet and renders it, handing over the attributes and handlers it wants on the element. The surface runs its own handler first and theirs after, unless the event was prevented. A right click selects what is under the pointer before any menu opens.
GeoView
a closed shape in a box (rectangle, ellipse, star, …), as a pen stroke (sketch) or as exact lines, with the words written in it.
DrawView
one freehand stroke, filled as the outline of where the pen went. A highlighter's stroke is a wide, even, see-through line instead.
LineView
a line or an arrow, straight or bent, as pen strokes (sketch) or as exact lines. Its run comes from lineGeometry, so an attached end follows its shape.
TextView
words on the canvas. The core cannot measure text, so the view tells the editor how large the words are on this screen (editor.setMeasured). That size is not part of the document: nothing is written for it.
FrameView
a frame's box, with its name above the top left corner.
TextLabel
the words of a shape, and the field they become while the shape is typed into (editor.editing). The element around it sets the typeface, size and alignment.
Minimap
the whole page small, with the part on screen marked. Press or drag in it to go there.
NoteView
a sticky note. Flat bright paper with a slightly darker band on top where the glue is, handwriting, and a slight tilt of its own (from its id, so it never changes), the way a note lands when it is stuck on by hand. It is paper, so it keeps its colour and dark writing in both themes. A view may be plain HTML; it need not be SVG.
ImageView
a picture, from the asset record the shape points at.
LinkView
a web address. A known video shows its player, any other address a card with where it leads. Like every shape it is moved and resized by the canvas; a double click makes it live (the card can be followed, the player played) until Escape.
